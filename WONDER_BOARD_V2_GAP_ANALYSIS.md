## 2. Priority Root Causes Addressed in V2

1. **P0 — Organic Single-Stroke Cloud Geometry & Visual Ink Bounds:** Compute true pixel-aware visual stroke bounds (`width + pressure`), expand with generous clearance (`max(18, 0.48*H)` horizontal, `max(14, 0.38*H)` vertical) around a rounded-capsule safe boundary (covering corners!), render puffy asymmetric cubic Bézier lobes with `fill="none"`, continuous chalk outline, collision checking against neighboring words, and arc-length sampled points (`0% -> 100%`) with tangent angles.
2. **P0 — Human-Like Single-Teacher Chalk Animation:** Implement sequential queue + `requestAnimationFrame` progressive single-path drawing (`cloud -> pause -> curved arrow -> pause -> handwritten correction -> handwritten explanation`) with an oriented chalk tip nib, zero shortcut closing line during progress `< 100%`, interruption/cancellation when target strokes change, and `prefers-reduced-motion` / speed options (`slow | natural | fast | instant`).
3. **P0 — Direct-on-Canvas Feedback:** Replace rectangular white tooltip popups with world-scaled handwritten chalk text directly on the `#F5EFE6` beige board.
4. **P0 — Real Recognition Boundaries & Silent AI Discipline:** Remove `"4 nét"` automatic stroke-count annotations cleanly, add compositional word/syllable recognition + incomplete Hangul fragment awareness (`IN_PROGRESS`), track provenance (`freehand_ink` vs `typed_vector` vs `fixture_sample`), and prevent AI Layer 4/5 output from entering recognition.
5. **P0 — Continuous N -> N+1 Incremental Pipeline:** Add dirty-region tracking, separate content vs geometry vs semantic revisions, detect multiple independent errors across single and multi-sentence boards, preserve completed annotations across pan/zoom/reload, and validate end-to-end in headless Chrome across all 16 required screenshots.
